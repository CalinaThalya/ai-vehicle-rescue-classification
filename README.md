### 📌 Projeto
 **Inteligência Artificial aplicada à automação de decisões operacionais** no setor de seguros e logística.


### 🎯 Objetivo do projeto

Utilizar **reconhecimento de imagens** para identificar o tipo de caminhão envolvido em uma ocorrência e recomendar automaticamente o **guincho mais adequado**, reduzindo tempo de atendimento e erros humanos.

### 🛠 Tecnologias

* Python
* Teachable Machine
* Jupyter Notebook
* Classificação de imagens
* Regras de decisão baseadas em confiança (>70%)
